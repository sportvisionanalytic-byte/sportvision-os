Environnement de review SportVision

Point d'entrée unique pour auditer l'écosystème SportVision (OS, Club+, Connect, Vitrine) sans jamais toucher à la production. Cet environnement est construit progressivement — voir l'état d'avancement par phase ci-dessous.

État actuel — Phase 1 uniquement
Aujourd'hui, ce Hub n'est que de la documentation statique. Aucune base de données Review, aucune clé Stripe test, aucun simulateur email/SMS n'existe encore. Le tableau ci-dessous (Architecture d'isolation prévue) décrit les garanties cibles que chaque phase suivante devra livrer et vérifier — pas un état déjà actif. La colonne « État » ci-dessous, et la page Status, font foi sur ce qui est réellement en place à un instant T.
