Phase 3 — Club+ Review

Application Club+ réelle (même code, corrections d'isolation ci-dessous), branchée sur Supabase Review — pas une maquette. sportvision-clubplus-review.netlify.app

Correctifs d'isolation apportés à l'app (bénéfiques aussi pour la production)
Deux vrais bugs trouvés en préparant ce déploiement, corrigés dans le code (identiques pour tous les environnements, aucun comportement changé en production puisqu'elle a déjà les bonnes variables) : (1) la CSP avait la référence Supabase de production codée en dur, ce qui aurait bloqué silencieusement tout appel vers un autre projet même avec les bonnes variables d'environnement ; (2) les clients Supabase utilisaient `!` (assertion TypeScript) sans aucun contrôle à l'exécution sur les variables requises — remplacé par un échec explicite. Un bandeau MODE REVIEW permanent a aussi été ajouté (actif uniquement si NEXT_PUBLIC_REVIEW_MODE=true, jamais en production) après avoir constaté que le badge de build existant affiche "Production" sur ce site aussi — c'est le nom du contexte de déploiement Netlify, pas un indicateur d'environnement.
